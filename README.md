# Лабораторная работа №4

Межпроцессное взаимодействие с использованием POSIX shared memory и именованных семафоров.

Родительский процесс запускает дочерний, который считывает числа из файла, вычисляет сумму чисел в каждой строке и передаёт результаты родителю через общую память.

## Сборка

Из корня проекта:

```bash
mkdir build
cd build
cmake ..
make
```

## Запуск

Из `build`:

```bash
./parent
```

Программа запросит путь к входному файлу.

Примеры относительных путей:

```text
../input.txt
../../input.txt
../tests/test1.txt
```

Пути указываются относительно текущей рабочей директории.

Пример содержимого файла:

```text
1 2 3
10 20 30
4.5 5.5
```

Ожидаемый результат:

```text
6
60
10
Child exit code: 0
```

## Пересборка после изменения кода

Из `build`:

```bash
make
```

## Полная пересборка

Из `build`:

```bash
cd ..
rm -rf build
mkdir build
cd build
cmake ..
make
```

## strace

Просмотр всех системных вызовов родительского и дочернего процессов:

```bash
strace -f ./parent
```

Просмотр создания процессов:

```bash
strace -f -e trace=clone,clone3,fork,vfork,execve ./parent
```

Просмотр операций с общей памятью:

```bash
strace -f -e trace=mmap,munmap,ftruncate ./parent
```

Сохранение трассировки в файл:

```bash
strace -f -o logs.txt ./parent
```

## Просмотр процессов

Просмотр процессов:

```bash
ps -ef
```

Просмотр дерева процессов:

```bash
pstree -p
```

## Общая память и семафоры

Используемые объекты:

- `/my_shared` — общая память для передачи результата и флага завершения.
- `/sem_ready` — уведомление родителю о готовности результата.
- `/sem_read` — подтверждение ребёнку, что результат прочитан.

В Linux объекты можно проверить:

```bash
ls -l /dev/shm/
```

После нормального завершения программы созданные IPC-объекты удаляются.

## Удаление оставшихся IPC-объектов

Если программа завершилась аварийно, именованные объекты могут остаться.

Для удаления объектов лабораторной (убедившись, что программа больше не запущена):

```bash
rm -f /dev/shm/my_shared
rm -f /dev/shm/sem.sem_ready
rm -f /dev/shm/sem.sem_read
```
